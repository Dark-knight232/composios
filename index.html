The three-pass pipeline with live single-app research trigger

Pass 1: Research

Composio SDK + Tavily search/extract → dual queries (dev docs + MCP) → LLM structured output (OpenAI/Anthropic/NIM)

Pass 2: Verification

Pass 3: Human Audit

Stratified 18-app sample (~18%) → human ground truth → accuracy scoring → root-cause → prompt fixes → pattern synthesis

✓ Automated by Agent

  • Dual Tavily queries per app (dev docs + MCP)
  • Tavily extract on top 2 official URLs
  • LLM structured synthesis (16-field schema)
  • Concurrency control + exponential backoff
  • Incremental checkpointing (resume-safe)
  • HTTP + headless URL verification
  • Diff tracking (pass_1 vs pass_2)

⚠ Human Required

  • Fake self-serve tiers (Plaid, Brex, Ramp)
  • Community vs Official MCP distinction
  • Stale/broken documentation URLs
  • Ambiguous product scope (NotebookLM, Devin)
  • Schema/prompt rule gaps (access_model nuance)
  • Enterprise gating verification
